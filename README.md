# Web-in Aja! — Business Plan Website

Website statis berbasis HTML, CSS, dan Vanilla JavaScript.

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka folder `web-in-aja-website` di VS Code.
3. Buka `index.html` langsung di browser atau gunakan ekstensi Live Server.

## Deploy ke GitHub Pages
Upload semua isi folder ke repository GitHub. Pada Settings → Pages, pilih branch utama dan folder `/ (root)`.

## Struktur
- `index.html` — struktur dan materi website
- `css/style.css` — desain responsif, tema, animasi
- `js/script.js` — navigasi, mode gelap/terang, scroll reveal, progress bar

## Catatan konten
Materi teks direkonstruksi dari PDF yang dikirim. Beberapa bagian dalam PDF tampak memakai teks contoh/template berbahasa Inggris (misalnya nama “Thynk AI”, baris strategi pasar, dan kontak contoh). Bagian tersebut dipertahankan dan diberi catatan jika relevan. Silakan periksa ulang angka/teks yang OCR PDF kurang jelas.
